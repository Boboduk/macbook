# AlcoveInspired

Нативное приложение для macOS 15 Sequoia и новее. Оно превращает область вокруг выреза
камеры MacBook в интерактивный остров в стиле Dynamic Island: музыка, HUD громкости и яркости,
таймер, заряд батареи и уведомления живут прямо у выреза и плавно раскрываются по клику,
наведению или событию.

Концепция вдохновлена [Alcove](https://tryalcove.com). Весь код и графика оригинальные, к
Alcove и Apple проект отношения не имеет. Что удалось узнать об Alcove и какой план из этого
получился, описано в [docs/PLAN.md](docs/PLAN.md).

* Swift 5 language mode, SwiftUI + AppKit + Core Animation, без сторонних зависимостей.
* Логика (очередь активностей, автомат состояний, раскладка, настройки, таймеры) вынесена
  в пакет `IslandCore`, который покрыт юнит-тестами и проверяется в том числе на Linux.
* В покое приложение не опрашивает систему: все источники событийные.

## Возможности

| Функция | Что делает | Как получает данные |
|---|---|---|
| **Остров** | Совпадает с вырезом в покое, подрастает при наведении, раскрывается по клику, наведению или свайпу вниз, закрывается при уходе курсора, клике вне острова или свайпе вверх. Может быть закреплён | Геометрия выреза из `NSScreen.safeAreaInsets` и `auxiliaryTopLeft/RightArea` |
| **Музыка** | Обложка и индикатор воспроизведения у выреза; в раскрытом виде трек, исполнитель, альбом, прогресс с перемоткой, ⏮ ⏯ ⏭; баннер при смене трека; свайп влево/вправо переключает треки | Apple Music и Spotify: публичные распределённые уведомления + AppleScript (разрешение «Автоматизация») |
| **Громкость** | HUD у выреза или под ним, уровень можно перетаскивать; баннер при смене устройства вывода (наушники, AirPods) | CoreAudio property listeners |
| **Яркость** | HUD при нажатии клавиш яркости, уровень можно перетаскивать | `DisplayServices` через `dlopen` + клавиши через `CGEventTap` |
| **Замена системного HUD** | Клавиши громкости и яркости обрабатывает приложение, системный OSD не появляется (⌥⇧ — мелкий шаг) | `CGEventTap` (разрешение «Универсальный доступ») |
| **Таймер и секундомер** | Обратный отсчёт с пресетами и ±минутами, пауза, сброс, круги; кольцо прогресса у выреза; звук и системное уведомление по окончании | На основе дат: корректен после сна и смены приложений, App Nap отключается только пока идёт отсчёт |
| **Батарея** | Подключение и отключение зарядки, полный заряд, предупреждение о низком заряде | IOKit power source notifications |
| **Уведомления** | Баннеры самого приложения: таймер, проблемы с разрешениями, смена устройства вывода | Единый менеджер активностей |
| **Настройки** | Общие, Внешний вид (с живым превью), Активности, Система (версии, разрешения, диагностика) | `UserDefaults`, один JSON-документ с миграцией |
| **Запуск при входе** | Переключатель в настройках | `SMAppService.mainApp` |

### Жесты и управление

| Действие | Результат |
|---|---|
| Клик по острову | Раскрыть или свернуть. Клик по баннеру открывает соответствующую вкладку |
| Наведение | Остров подрастает; при «Наведение → Раскрывать» раскрывается после задержки |
| Свайп двумя пальцами вниз / вверх по острову | Раскрыть / свернуть или скрыть баннер |
| Свайп влево / вправо | Следующий / предыдущий трек, когда показана музыка |
| Правый клик | Меню: раскрыть, закрепить, скрыть остров, быстрый таймер, настройки, выход |
| Иконка в строке меню | То же меню. Её можно скрыть, а настройки открываются и при повторном запуске приложения |

## Установка

### Готовая сборка

Каждый push собирается в GitHub Actions на macOS. Готовый `AlcoveInspired.app` лежит в
артефакте **AlcoveInspired-app** у последнего успешного запуска workflow **Build**
(вкладка *Actions* репозитория).

1. Скачайте и распакуйте `AlcoveInspired.zip`.
2. Перенесите `AlcoveInspired.app` в `/Applications`.
3. Сборка подписана ad-hoc, а не сертификатом разработчика, поэтому при первом запуске
   откройте её через **правый клик → Открыть** или выполните:
   ```bash
   xattr -dr com.apple.quarantine /Applications/AlcoveInspired.app
   ```

### Сборка в Xcode

Нужен Xcode 16 или новее (проект использует синхронизируемые папки Xcode 16).

1. Откройте `AlcoveInspired.xcodeproj`.
2. Выберите схему **AlcoveInspired** → *My Mac* и нажмите ⌘R. Тесты `IslandCore` запускаются
   по ⌘U.
3. Чтобы разрешения «Универсальный доступ» и «Автоматизация» не сбрасывались после каждой
   пересборки, в *Signing & Capabilities* выберите свою команду (Team) и *Automatic signing*.
   По умолчанию проект подписывается ad-hoc («Sign to Run Locally»), а macOS привязывает
   разрешения к подписи.

### Сборка из командной строки

```bash
# Release-сборка через Xcode → build/AlcoveInspired.app
Scripts/build-app.sh

# То же и установка в /Applications с перезапуском
Scripts/build-app.sh --install

# Без Xcode, только Command Line Tools (SwiftPM + iconutil + codesign)
Scripts/build-app.sh --spm

# Напрямую через xcodebuild
xcodebuild -project AlcoveInspired.xcodeproj -scheme AlcoveInspired \
  -configuration Release -destination 'generic/platform=macOS' \
  -derivedDataPath build/DerivedData CODE_SIGN_IDENTITY=- build

# Тесты ядра
swift test --package-path Packages/IslandCore
xcodebuild test -project AlcoveInspired.xcodeproj -scheme AlcoveInspired -destination 'platform=macOS'
```

### Разрешения

Приложение ничего не запрашивает при запуске. Каждое разрешение запрашивается, только когда
вы включаете или впервые используете функцию, которой оно нужно:

| Разрешение | Когда понадобится | Без него |
|---|---|---|
| Автоматизация → Music / Spotify | Кнопка «Allow» в музыкальной панели или первое нажатие ⏯ | Название трека и состояние воспроизведения видны, обложки, прогресса и управления нет |
| Универсальный доступ | «Replace the system HUD» или HUD яркости | HUD громкости работает, HUD яркости и замена системного HUD недоступны |
| Уведомления | «System notification when finished» у таймера | Остаётся баннер в острове и звук |
| Вход в систему | Переключатель «Launch at login» | — |

## Архитектура

```
Packages/IslandCore/            ← чистый Swift + Foundation, 98 юнит-тестов (macOS и Linux)
  Activity.swift                  модель активности: тип, приоритет, заголовок, описание,
                                  время появления, длительность, правила обновления и возврата
  ActivityManager.swift           единая очередь: live-активности + временные, вытеснение,
                                  возврат к предыдущей, удержание под курсором, ограничение очереди
  IslandController.swift          конечный автомат взаимодействия → IslandPresentation
  EventRouter.swift               события модулей + настройки → активности; журнал диагностики
  IslandLayout.swift              размеры и радиусы для всех состояний (от реальной геометрии выреза)
  IslandSettings.swift            Codable-настройки, проверка диапазонов, устойчивая загрузка
  Timers.swift, NowPlaying.swift, Input.swift, Power.swift, Scheduler.swift

AlcoveInspired/                 ← приложение (всё содержимое папки входит в target автоматически)
  App/        точка входа, AppDelegate, AppModel (композиция), status item, окно настроек
  Core/       IslandCoordinator (мост Core ↔ SwiftUI/AppKit, выбор анимаций), MainQueueScheduler
  Window/     IslandPanel (NSPanel), IslandHostingView, геометрия выреза, DisplayObserver,
              MouseTracker (сквозные клики и hover), FullscreenDetector, IslandWindowController
  Services/   CoreAudio, DisplayServices, IOKit power, AppleScript, разрешения, вход в систему,
              SettingsStore
  Features/   Music, Volume, Brightness, Timer, Power, Notifications, MediaKeys
  UI/         IslandRootView, IslandShape, Compact/Banner/Expanded, ActivityViews, Components, Settings
  Resources/  Assets.xcassets (иконка, акцентный цвет), ru.lproj

Config/       Info.plist, entitlements
Scripts/      build-app.sh, ci-smoke-test.sh, test-core-linux.sh, generate_xcodeproj.py, generate_icon.py
```

Поток данных:

```
модуль (Music, Volume, Timer…) ──IslandEvent──▶ EventRouter ──Activity──▶ ActivityManager
                                                                               │ onChange
SwiftUI ◀── presentation (с анимацией) ◀── IslandCoordinator ◀── IslandController
AppKit (панель, hover, клики, жесты) ─────────────────────────▶ IslandController
```

### Как добавить новую активность (например, календарь)

1. В `IslandCore`: добавить case в `ActivityKind` и событие в `IslandEvent`, описать в
   `EventRouter.handle(_:)`, как событие превращается в `Activity` (стиль, приоритет,
   длительность), и добавить секцию в `IslandSettings`.
2. В приложении: создать контроллер в `Features/Calendar`, который отправляет событие через
   `onEvent`, и связать его в `AppModel.wireEvents()`.
3. Добавить представления для compact/banner в `CompactIslandView` / `BannerIslandView`.

Окно, анимации, очередь, удержание и настройки сюда не входят: они уже общие.

### Решения, которые стоит знать

* **Одно окно на всё время работы.** `NSPanel` максимального размера создаётся один раз и
  никогда не меняет размер во время анимаций; анимируются только SwiftUI-фигура и содержимое.
  Поэтому нет мерцания и пересоздания окон.
* **Сквозные клики.** `ignoresMouseEvents` выключается только пока курсор над *целевым*
  прямоугольником острова, поэтому прозрачная часть панели никогда не перехватывает клики.
* **Уровень окна `.mainMenu + 3`.** Остров выше строки меню и статус-иконок, но ниже
  выпадающих меню. Поведение `.canJoinAllSpaces`, `.stationary`, `.fullScreenAuxiliary`,
  `.ignoresCycle`. Все параметры прокомментированы в `Window/IslandPanel.swift`.
* **Анимации.** Рост — пружина с лёгким перелётом, сжатие — без отскока, обновления на месте
  не анимируют размер. Смена содержимого идёт через blur/fade/scale в той же транзакции.
  Скорость настраивается. Индикатор воспроизведения на Core Animation.
* **Без выреза.** На внешних мониторах и Mac без выреза остров — пилюля в центре строки меню
  (её можно скрыть до наведения).

## Производительность и конфиденциальность

* В покое приложение ничего не делает: нет таймеров и опроса. Hover определяется мониторами
  событий мыши, которые срабатывают только при движении.
* `TimelineView` работают только пока соответствующий элемент виден (прогресс трека — раз в
  секунду, секундомер с сотыми — только в раскрытом виде).
* Настройки хранятся локально в `UserDefaults`. Телеметрии нет, регистрации нет.
* Единственный сетевой запрос — загрузка обложки Spotify по https-URL, который даёт сам
  Spotify. Его можно отключить.
* Названия треков и текст уведомлений нигде не сохраняются. Журнал диагностики хранит только
  типы событий, живёт в памяти и очищается при выходе.

## Ограничения (технические ограничения macOS)

| Ограничение | Причина | Что сделано |
|---|---|---|
| Музыка только из Apple Music и Spotify | `MediaRemote` приватный и с macOS 15.4 закрыт для сторонних приложений | Документированные уведомления и словари AppleScript двух плееров |
| Яркость использует приватный `DisplayServices` | Публичного API для встроенного дисплея на Apple Silicon нет | Загрузка через `dlopen` без линковки; без символов модуль сообщает «недоступно» |
| Изменение яркости из Пункта управления не показывается | Нет уведомления об изменении яркости | HUD реагирует на клавиши яркости |
| Уведомления других приложений не показываются | Содержимое Центра уведомлений недоступно сторонним приложениям | Показываются уведомления самого приложения |
| Нет острова на экране блокировки | Нужны приватные SkyLight API | Не реализовано |
| Ad-hoc подпись сбрасывает разрешения после пересборки | macOS привязывает TCC к подписи | Подпишите своей командой в Xcode |
| Индикатор воспроизведения — анимация, а не спектр | Захват системного звука требует отдельного разрешения | Честно назван «индикатором воспроизведения» |
